# NebulaCh-Linux
**NebulaCH** is a Debian-based Linux distribution focused on customization, freedom, gaming, and choice.

## 🧪 Current Status

NebulaCH is currently in **Pre-Alpha** development.

The current development build uses the Cinnamon desktop and is being built with Debian Live Build.

## 🚀 Project Goals

NebulaCH is being designed to provide:

- Multiple desktop experiences
- Chromium-based browsing
- A unified NebulaCH Settings system
- Gaming support
- Windows software compatibility
- An app store
- A graphical update system
- Extensive customization

## 🖥️ Current Build

**NebulaCH 0.2 — Cinnamon**

Current foundation:

- Debian
- Cinnamon
- Xorg
- LightDM
- Live-build

## 🛠️ Development

NebulaCH is actively being developed.

Features may change, break, or be replaced during the pre-alpha period.
